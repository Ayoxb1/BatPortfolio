## 🚀 PRÓXIMOS PASOS

### 1️⃣ Instalar (15 minutos)
```bash
# Crear proyecto
npx create-next-app@latest . --typescript --tailwind

# Copiar archivos
cp ScrollyCanvas.tsx src/components/
cp Overlay.tsx src/components/
# ... resto de componentes

# Copiar frames
cp -r sequence public/sequence/

# Instalar y ejecutar
npm install
npm run dev
```

### 2️⃣ Verificar en navegador
- Abre: http://localhost:3000
- Verifica que tu foto anima con scroll
- Prueba todos los links (LinkedIn, GitHub)

### 3️⃣ Personalizar (opcional)
- Cambiar colores en `tailwind.config.ts`
- Cambiar fuentes en `layout.tsx`
- Agregar más proyectos en `Projects.tsx`
- Ver `PERSONALIZACION_COMPLETA.md` para más

### 4️⃣ Deploy en Vercel (2 minutos)
```bash
npm i -g vercel
vercel
# Tu portfolio en vivo en: https://tu-portfolio.vercel.app
```

### Agregar nuevo proyecto
En `src/components/Projects.tsx`:
```typescript
{
  id: '5',
  title: 'Nuevo Proyecto',
  description: 'Descripción...',
  tags: ['Tech1', 'Tech2'],
```

En `src/globals.css`:
